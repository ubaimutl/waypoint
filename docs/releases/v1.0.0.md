# Waypoint v1.0.0 — First public release

Waypoint is a self-hosted Android device locator with a web dashboard.

**This project is under active development and testing.** Background reliability, battery consumption, and location accuracy vary by device and network. Do not rely on Waypoint as your only recovery method.

## Features

- Request your phone’s location remotely.
- Built-in internet connection without an additional app.
- Optional UnifiedPush, signed SMS wake-up, and periodic checks.
- Multiple devices with separate, revocable credentials.
- Password-protected dashboard with optional authenticator-based 2FA and recovery codes.
- Docker deployment with persistent storage.
- Optional Cloudflare Access support; Cloudflare is not required.

## Testing status

Development testing has demonstrated screen-off location requests and reconnection after restarts on one physical Android device. Broader device coverage and longer battery testing are still needed. Waypoint has not undergone an independent security audit.
