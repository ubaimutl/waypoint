# Waypoint v1.1.0

One account for your devices, native Android maps, remote ringing, and lower standby connection traffic.

## Changes

- Sign in to your server from Android using the dashboard password, followed by a two-factor code when enabled. New phones enroll automatically; existing tracking credentials remain usable.
- See and locate your other devices from the Android map, with native Devices, This phone, and Account navigation.
- Play a sound remotely, with duration, volume, vibration, and stop controls. Ringing can sound through Do Not Disturb.
- Revoke a phone's access to other devices from the dashboard while keeping that phone trackable. Account access and background tracking use separate credentials.
- Use a compact, map-first dashboard and Android interface with a green accent, system/light/dark themes, and optional glass panels. Notes are tucked behind information buttons.
- Reduce built-in connection maintenance: two-minute application heartbeats, opportunistic maintenance batching, and suppression of redundant pending-request polls after a confirmed empty queue. Offline retry suspension, network recovery, and bounded location acquisition remain supported.

Waypoint uses very little battery in our standby testing. Results vary by device, network and selected options; no universal saving percentage is claimed. If you notice unexpected drain, [open an issue](https://github.com/ubaimutl/waypoint/issues/new) with your phone model, Android/app versions, connection mode, and battery-usage screenshot.

## Upgrade from v1.0.0

1. Back up the persistent server data volume, including `secrets.key`. Retain the existing environment and credentials.
2. Upgrade the server to `ghcr.io/ubaimutl/waypoint:1.1.0` before updating Android.
3. Install `waypoint-1.1.0.apk` over the official v1.0.0 APK. Version code is 27; the original release signing certificate must be retained.
4. Existing tracking configuration remains supported. Signing in on Android is optional and enables access to your other devices. Existing phones without ringing support can still report locations; update their APK to enable ringing.

The database changes are additive. Do not rerun setup to generate replacement credentials during an upgrade. Debug-signed previews cannot update official release APKs in place because their signing certificates differ. A server rollback should use a matching data backup.

## Release packages

- Android: `waypoint-1.1.0.apk`, signed with the original release certificate.
- Docker: `ghcr.io/ubaimutl/waypoint:1.1.0`, Linux AMD64 and ARM64.
- `SHA256SUMS` and `SIGNING-CERTIFICATE.txt` for the downloadable APK.

## Validation

All 54 server tests passed, including device isolation, migration, account access/revocation, MFA, ringing, and connection behavior. Android release, debug, and instrumentation APK builds passed. Dashboard and app screenshots use sample devices and public coordinates. Physical-device testing demonstrated successful location requests, remote ringing, and low standby drain; coverage across other devices and networks remains limited.

Waypoint remains under active development and has not undergone an independent security audit. Do not rely on it as your only recovery method.
